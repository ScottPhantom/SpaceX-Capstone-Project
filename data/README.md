# Data files

The CSV files in this folder come from the IBM Skills Network Applied Data Science Capstone course:

- `dataset_part_1.csv` - API-derived Falcon 9 launch records before target creation
- `dataset_part_2.csv` - cleaned records with binary landing target `Class`
- `dataset_part_3.csv` - one-hot encoded numeric model features
- `Spacex.csv` - launch records used for the SQL lab
- `spacex_launch_dash.csv` - data used by the Plotly Dash application
- `spacex_launch_geo.csv` - coordinates and outcomes used by the Folium lab

These datasets form a course snapshot ending in November 2020. They do not represent current SpaceX operations.
